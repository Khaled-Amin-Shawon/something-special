# Birthday Surprise Webpage 💝

A beautiful and interactive birthday surprise webpage with animations, slideshow, and heartfelt messages.

## Features ✨

- 🎉 Interactive splash screen with countdown
- 🖼️ Beautiful image slideshow with messages
- 💌 Heartfelt birthday letter with animations
- 💖 Cute popup messages
- 🎆 Fireworks and confetti effects
- ✨ Sparkle animations
- 📱 Fully responsive design

## Technologies Used 🛠️

- HTML5
- CSS3
- JavaScript
- Google Fonts (Dancing Script)

## Setup Instructions 📋

1. Clone the repository:

```bash
git clone [repository-url]
```

2. Open the project folder:

```bash
cd birthday-surprise
```

3. Open `index.html` in your web browser

## File Structure 📁

```
birthday-surprise/
├── index.html          # Main HTML file
├── styles.css          # Main styles
├── splash.css          # Splash screen styles
├── script.js           # JavaScript functionality
└── img/               # Image directory
    ├── img.jpg
    ├── img1.jpg
    ├── img2.jpg
    ├── img3.jpg
    ├── img4.jpg
    └── img6.jpg
```

## Customization 🎨

1. Replace images in the `img` folder with your own images
2. Modify messages in `index.html`
3. Adjust colors and animations in `styles.css`
4. Customize timing in `script.js`
